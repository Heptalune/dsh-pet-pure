# 纯桌宠变体（pure variant）

> **定位**：只保留桌宠本体的轻量构建——动画播放、点击/拖拽/物理/多开、自言自语
> 文字气泡、点击音效、托盘与右键菜单、设置、角色切换与素材页。其余一切可选功能
> 与 AI 联动全部不出场，安装包显著更小。
>
> **构建**：`powershell -ExecutionPolicy Bypass -File scripts\build_pure.ps1`
> （可选 `-SkipHotFrameseq` 得到极致轻量包）；安装器用 Inno Setup 6 编译
> `packaging\dsh-pet-pure.iss`。

## 砍掉了什么（三层）

| 层 | 手段 | 内容 |
|---|---|---|
| 行为 | `DSH_PET_PURE=1`（入口 `packaging/pet_entry_pure.py` 在 import 前设置）→ `feature_activation.decide_and_freeze` / `freeze_for_settings_process` 冻结空启用集 | 16 个可选功能模块全部停用：AI 对话、看看屏幕/截图识屏、主动识屏、文件解读、Agent 联动、灵动岛、音乐/歌词、语音报时(TTS)、天气、抽签、待办、节日、快捷启动、直播捕获、跨屏、系统工具。菜单/服务/热键/设置页经既有 `is_active` 门控自动消失 |
| 行为（补充） | 菜单注册表 `available=False` + 托盘分支 + 不挂回调 | DeepSeek 网页入口、余额、在线更新（检查更新/更新页）、夸克网盘、彩蛋配图（素材不随包） |
| 资源 | 构建脚本不打包 | `assets/chat`（聊天壁纸）、`assets/big_blue_fat_fish`（彩蛋图 16MB）、`resources/`（OCR 模型 31MB + presentmon）、`integrations/`（DSH 桥接插件） |
| 依赖 | 专用 venv（`.venv-pure`，`requirements-pure.txt`） | 不装 rapidocr/onnxruntime/opencv/numpy（OCR 全家）、winrt/psutil（歌词/指标）、edge-tts、keyring、pycaw、lunar-python、certifi |

**保留的桌宠本体**：WebM/帧序列动画引擎、动画链状态机、漫游/拖拽/弹射/碰撞物理、
边缘探头、多开多宠、点击回应与文字气泡（本地台词）、点击音效（winmm 直放）、
托盘/右键菜单、现代设置页（常规/桌宠/互动/菜单四域）、角色热加载与角色包下载页、
开机自启、鼠标穿透、全屏自动隐藏等窗口行为。

## 为什么这样砍是安全的

- **AI 功能本就硬依赖 chat**：`file_interpret` / `vision` / `proactive` 在
  `pet/features.py` 里 `requires=("chat",)`，chat 被排除后依赖闭包自动把它们全部
  关停；`pet/app.py` 对 `pet.chat` 的所有导入都有能力守卫（no-chat 变体的既有机制）。
- **功能模块三层门控**（菜单 `available_ids` / 设置页 `is_active` 投影 / 执行层）
  是上游既有架构（`docs/PR-REPORT-FEATURE-MODULES-2026-10-21.md`），纯变体只是把
  启用集钉死为空，不新造门。
- **升级安装不复活功能**：`decide_and_freeze` 在纯变体里先于「新装/升级判定」返回
  空集，即使数据目录里有旧的启用列表也不生效；主/设置两个进程都有同一道守卫。

## 素材与白边

- 随包携带**全部 106 段 WebM**（≈53MB），角色开箱即有完整动作池。
- WebM 的半透明像素混有白底，直播存在白边；构建默认预转**核心 11 段**
  （idle/move/turn/click/drag，与官方发布同口径）为无损帧序列，覆盖 ≈95% 播放
  时长；冷集动画由运行时「首跑自动供给」按每次启动 1 段的预算逐步升级。
  `-SkipHotFrameseq` 可省掉这 ≈137MB，代价是热集也要等运行时转换。

## 数据目录与共存

`packaging/build_variant.py` 写入 `VARIANT='pure'` → 数据目录为
`dsh-pet-standalone-pure`，与完整版（`*-webm-chat` 等）完全隔离，可并存互不干扰。

## 已知取舍

- 在线更新被整体移除：更新源指向完整版仓库，静默装回会顶掉纯版。升级纯版 =
  重新构建/重新安装。
- 角色包下载页保留（下载的是动画素材包，与 AI 无关），但源指向上游 release。
- 「看看屏幕」依赖的本地 OCR 属 `vision` 模块，纯变体不装其模型与推理库。
